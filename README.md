# 公交到站（老人版）

一个给家里老人用的公交车到站查询：没有广告、没有弹窗、字大、三步查完。
数据来自温州「掌上公交」的公开接口。页面和全市站库都装在 App 里，**自己上网查，不依赖电脑**；
同一套前端也能在电脑上跑（`server.py`），方便改代码时预览。

## 它解决什么问题

「掌上公交」查一趟车要点四五下、还要先看广告。这里只做一件事：
**知道 36 路还有几站到石坦，该什么时候出门。**

## 站库：全市 6909 个站

`bus-app/stations.json` 是从上游线路站表汇总下来的全市站点坐标表：**6909 个站名、
13793 个站台点**，覆盖市区、苍南、泰顺、永嘉、平阳、文成、洞头。

它撑着两件事：

- **附近的站** —— 按定位筛半径内的站，不用联网查，本地算距离
- **站名搜索** —— 本地秒出，按「距离 + 名字贴合度」排，全市 163 个跨县重名的站也不会点错

要更新（上游新开站了）就重跑抓取脚本，约 40 秒：

```bash
cd bus-app
python build_stations.py          # 全量重抓
python build_stations.py --merge  # 只补新站
```

> 乐清、瑞安不在这个数据源里（上游城市清单里没有这两个条目），站库里那点坐标只是过路站。

## 字看不清怎么办

**设置 → 字大小**，三个按钮分别是「标准 / 大 / 特大」，按钮里的「站」字就是实际大小，
不识字也能照着大小挑。默认是「大」。

- 特大档会把线路行改成两行（线路号一行、方向一行），一屏少放几条，但字不会被切
- 广告位、小标签、距离这些辅助字放得最多（11.5px → 19px），到站大数字只微调（96 → 104px）
- 换完自己记住，下次打开还是这个大小

## 不认识字也能用

每个页面底部都有一个「念一遍」按钮，点一下用手机自带的语音念这一页最要紧的一句：

```
到站卡片 → 「36路，往浙南科技城。还有14分钟，车在前面9站。该出门了。」
站牌页   → 「石坦站，36路，往九山5分钟、往浙南科技城14分钟。」
选方向   → 「36路，2个方向。往浙南科技城，2辆车在路上。」
```

**手机没装中文语音也能念** —— 常用词、数字和整句短语（297 段）已经录好打包在 App 里，
系统没有语音引擎时就用它们拼出这句话，只是不含站名（站名几万个，录不了）：
「三十六路，还有十四分钟，车在前面九站。该出门了。」

「该出门了」是算出来的：她到那个站的步行时间（按 50 米/分钟、直线距离 ×1.3）
和车还有几分钟比。算不出距离就不说这句 —— 宁可不说，也不让她白跑。

## 装到手机上：不依赖电脑

安装包在 `dist/`（当前 `bus-arrival-1.2.4-12303cc3.apk`，约 3.3 MB，v1+v2 签名）。

**V1.1.0 起 App 自带页面和全市站库，自己上网查，不需要电脑、不需要服务器。**
出门在外只要有网就能用。想在家走电脑（局域网更快、更省流量）也行，在设置里填地址即可。

手机上怎么拿：

- 下载页（推荐）：https://howtosurrvive.github.io/bus-arrival/ —— 页面上挂了四条直链
  （Release / Pages / jsDelivr / raw），一条打不开就换下一条
- Release 列表：https://github.com/howtosurrvive/bus-arrival/releases
- 想直接发给别人扫：`docs/qr-download.png` 就是下载页的二维码

文件名和校验值**以 `dist/` 为准**（`dist/apk-info.json` 里记着 sha256）。
下载页上那个哈希对不上就别装 —— 说明拿到的是 CDN 缓存的旧包。

## 电脑上跑（开发预览 / 不想装 App 时）

```
1. 电脑装 Python 3（勾上 Add to PATH）
2. 双击 bus-app\启动.bat
3. 手机连同一个 WiFi，浏览器打开 http://<电脑IP>:8765
```

## 打包 APK

需要 JDK 17 和 Android SDK build-tools（工具链说明见 `HANDOFF.md`）。

```bash
cd android
bash build.sh                          # 默认：自带数据，不连电脑
bash build.sh http://192.168.1.9:8765  # 想默认连电脑上的 server.py 才传地址
```

产物在 `android/build-<月日时分>/bus-1.2.4.apk`；正式包会被自动复制到 `dist/`，
并同步改写下载页上的文件名、SHA-256、证书指纹。**别手改下载页上的哈希**。
